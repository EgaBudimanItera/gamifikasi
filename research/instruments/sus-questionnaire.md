# System Usability Scale (SUS) Questionnaire

## Instrumen SUS untuk Evaluasi EduQuest

### Petunjuk Pengisian
Harap menilai setiap pernyataan berikut berdasarkan pengalaman Anda menggunakan sistem EduQuest. Berikan skor dari 1 (Sangat Tidak Setuju) hingga 5 (Sangat Setuju).

### Skor
1 = Sangat Tidak Setuju
2 = Tidak Setuju
3 = Netral
4 = Setuju
5 = Sangat Setuju

---

### Pernyataan

| No | Pernyataan | 1 | 2 | 3 | 4 | 5 |
|----|-----------|---|---|---|---|---|
| 1 | Saya pikir saya akan sering menggunakan sistem ini | ☐ | ☐ | ☐ | ☐ | ☐ |
| 2 | Saya menemukan sistem ini tidak perlu kompleks | ☐ | ☐ | ☐ | ☐ | ☐ |
| 3 | Saya pikir sistem ini mudah digunakan | ☐ | ☐ | ☐ | ☐ | ☐ |
| 4 | Saya pikir saya perlu bantuan teknis untuk menggunakan sistem ini | ☐ | ☐ | ☐ | ☐ | ☐ |
| 5 | Saya menemukan berbagai fungsi dalam sistem ini terintegrasi dengan baik | ☐ | ☐ | ☐ | ☐ | ☐ |
| 6 | Saya menemukan terlalu banyak ketidakkonsistenan dalam sistem ini | ☐ | ☐ | ☐ | ☐ | ☐ |
| 7 | Sebagian besar orang akan belajar menggunakan sistem ini dengan cepat | ☐ | ☐ | ☐ | ☐ | ☐ |
| 8 | Saya menemukan sistem ini sangat rumit untuk digunakan | ☐ | ☐ | ☐ | ☐ | ☐ |
| 9 | Saya merasa sangat percaya diri menggunakan sistem ini | ☐ | ☐ | ☐ | ☐ | ☐ |
| 10 | Saya perlu mempelajari banyak hal sebelum bisa menggunakan sistem ini | ☐ | ☐ | ☐ | ☐ | ☐ |

---

### Cara Menghitung Skor SUS

1. **Untuk item ganjil (1, 3, 5, 7, 9):** Kurangi 1 dari skor yang diberikan
2. **Untuk item genap (2, 4, 6, 8, 10):** Kurangi skor yang diberikan dari 5
3. **Jumlahkan** semua skor yang sudah dikonversi
4. **Kalikan** jumlah dengan 2.5

**Rumus:** SUS Score = (Total Skor Konversi) × 2.5

### Interpretasi

| Skor SUS | Kategori | Keterangan |
|----------|----------|------------|
| > 80.3 | Excellent | Sangat mudah digunakan |
| 68-80.3 | Good | Mudah digunakan |
| 51-68 | OK | Cukup mudah digunakan |
| 25-51 | Poor | Sulit digunakan |
| < 25 | Awful | Sangat sulit digunakan |

### Target Penelitian
- SUS Score ≥ 70 (Good)
- Evaluasi dilakukan pada 30-50 responden
- Responden terdiri dari siswa SMA/SMK
